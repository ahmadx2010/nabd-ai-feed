جوجل تطلق «استرجاع الأدوات» في Gemini API لتقليل التوكنات وتحسين دقة الوكلاء

Introducing Tool Retrieval in the Gemini API

أطلقت جوجل ميزة «استرجاع الأدوات» (Tool Retrieval) بنسخة معاينة في Interactions API ضمن Gemini API، لمساعدة المطورين على إدارة مكتبات كبيرة من الأدوات داخل وكلاء الذكاء الاصطناعي بكفاءة أعلى.

عندما يرتبط الوكيل بعشرات أو مئات الأدوات، فإن إرسال مخطط المعاملات الكامل لكل أداة في كل طلب يرفع عدد توكنات الإدخال ويزيد زمن الاستجابة ويقلل دقة اختيار الأداة المناسبة. تحل الميزة ذلك بإبقاء المكتبة جاهزة وتحميل التفاصيل عند الحاجة فقط.

• طريقة التفعيل: إضافة أداة tool_search إلى الطلب وضبط defer_loading على true للأدوات المراد تأجيل تحميلها.
• يظل النموذج يرى اسم ووصف كل أداة مؤجلة، فيعرف ما هو متاح، بينما تبقى مخططات المعاملات خارج السياق.
• عند احتياج النموذج إلى أداة يطلبها بالاسم، فيحمّل الـ API مخططها الكامل ثم يستدعيها.
• تعمل الميزة مع Gemini 3.6 والنماذج الأحدث، وهي متاحة اليوم في Interactions API.
• الفوائد: خفض عدد توكنات الإدخال، وتقليل زمن الاستجابة، وتحسين الدقة.

تكمن أهمية الخطوة في أنها تجعل بناء وكلاء يتعاملون مع عدد كبير من الأدوات أرخص وأسرع وأكثر دقة.
