VS Code يتقاعد من «Local harness» في فبراير 2027 لصالح Copilot harness

VS Code retires the Local harness in February 2027

أعلنت GitHub أن إصدار Visual Studio Code 1.146 يُوقف استخدام «Local harness»، وهو البرنامج الأقدم الذي ينسّق النموذج والسياق والأدوات في جلسات وكيل GitHub Copilot داخل المحرر، وسيتم حذفه في فبراير 2027.

بديله Copilot harness مدمج في VS Code وهو الافتراضي للجلسات الجديدة منذ الإصدار 1.143، ولا ينقل ملفاتك إلى السحابة.

• مبني على Copilot SDK ويشارك بيئة التشغيل نفسها مع Copilot CLI وتطبيق GitHub Copilot.
• يمكن متابعة الجلسة نفسها بين المحرر ونافذة Agents.
• يتيح لـ Copilot Fusion اختيار النماذج وتنسيق المسودات والمراجعة في الباقات المدعومة.
• أذونات مساعدة تقلل مقاطعات الموافقة.
• موصلات Copilot (معاينة) للوصول إلى خدمات الفريق دون إعداد خوادم MCP.
• لوحات المهام والرسوم التفاعلية (معاينة).
• يتيح للمسؤولين فرض أذونات تشغيل وقيود عزل لا يفرضها Local harness.

يبقى Local harness متاحاً خلال فترة انتقالية مدتها ثلاثة أشهر حيث تسمح سياسة المؤسسة. على المستخدمين بدء جلسة جديدة واختيار Copilot ضمن Session Target ومراجعة توافق تخصيصاتهم قبل فبراير 2027.

أهمية الخبر: تتجه GitHub لتوحيد بيئة وكلاء البرمجة على محرك واحد، وعلى الفرق الاستعداد للانتقال.
